# ARTEX provenance

This tree is [Autumn-27/ARTEX](https://github.com/Autumn-27/ARTEX) based on commit `160fe13`, with the
original ARTEX product name restored everywhere (interface, documentation, distribution targets).
An intermediate rebrand existed under a different name; nothing else about the code was changed
beyond that naming.

The `LICENSE` is retained unchanged. Original authorship, contributor acknowledgments and upstream
changelog history remain attributed to ARTEX by Autumn-27. The Go module `github.com/Autumn-27/artex`,
source entry point `./cmd/artex`, `ARTEX_*` configuration contracts, `artex` database defaults and
`ARTEX` login username are original. The executable is `artex` (`artex.exe` on Windows); archive
names follow `artex-<version>-<os>-<arch>.zip`. Docker Compose builds the checked-out source locally.
